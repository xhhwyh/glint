# Changelog

## 0.1.0

First packaged release of Glint, a terminal coding agent.

- Install prebuilt binaries on macOS (Apple Silicon / Intel) and Linux / WSL (ARM64 / x86_64).
- Set up built-in API providers, custom OpenAI-compatible endpoints, or native ChatGPT subscription login.
- Keep context, approvals, tools and saved conversations under Glint's own orchestration.
- Select supported model reasoning efforts with an inline keyboard-controlled scale and per-model persistence.
- Navigate setup with keyboard or mouse, and reopen recent conversations from the dashboard.
- Extend coding workflows with MCP, plugins, LSP and subagents.

See the README for installation, required tools, first-run setup and upgrades.
